Fix IP problem for X410. Cant find screen problem - UBUNTU Noble Numbat 24.04 and UKUI

FIRST OPEN POWERSHELL AND TYPE: ipconfig 

Last lines are IP-number for WSL.

SAVE IP HERE: 172.30.16.1

GO BACK TO UBUNTU Noble Numbat 24.04 Terminal AND COPY AND PASTE THIS IN TERMINAL.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here from POWERSHELL and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed for UBUNTU Noble Numbat 24.04 LTS and UKUI.

DONT STRESS IF YOU PUT WRONG IP ALL WILL STOP WORKING UNDER LINUX.

Now we must install scrip for UKUI AND UBUNTU Noble Numbat 24.04 LTS

Copy and paste in terminal all =]

sed -i 's/\r$//' /tmp/ubuntu-UKUI.sh
bash -n /tmp/ubuntu-UKUI.sh && echo "Syntax OK"
sudo mkdir -p ~/.local/bin
sudo chown -R "$(id -un):$(id -gn)" ~/.local
install -m 755 /tmp/ubuntu-UKUI.sh ~/.local/bin/ukui-x410
ls -l ~/.local/bin/ukui-x410
grep -qxF 'export PATH="$HOME/.local/bin:$PATH"' ~/.bashrc || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
command -v ukui-x410
