Installing Visual Studio Code on UBUNTU 26.04

Visual Studio Code is a new choice of tool that combines the simplicity of a
code editor with what developers need for the core edit-build-debug cycle.

Watch story about VS code: https://www.youtube.com/watch?v=kHL3XzjpT5w

Visual Studio Code is available on Linux through official Debian, RPM,
and Snap packages. Community-maintained packages are also available for
Arch Linux and Nix.

Copy and paste in terminal for UBUNTU.

echo "code code/add-microsoft-repo boolean true" | sudo debconf-set-selections 

sudo apt install wget gpg &&
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | sudo gpg --dearmor -o /usr/share/keyrings/microsoft.gpg

Create /etc/apt/sources.list.d/vscode.sources and file with these contents.

sudo nano /etc/apt/sources.list.d/vscode.sources

Types: deb
URIs: https://packages.microsoft.com/repos/code
Suites: stable
Components: main
Architectures: amd64,arm64,armhf
Signed-By: /usr/share/keyrings/microsoft.gpg

sudo apt update &&
sudo apt install code code-insiders

Fix IP problem for X410. Cant find screen problem.

Open Powershell from Microsoft and type: ipconfig

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL.

SAVE IP FROM POWERSHELL HERE: 172.30.16.1

GO BACK TO Ubuntu 26.04 Terminal AND COPY AND PASTE THIS IN TERMINAL.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1  <-- put your ip here from powershell and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf
