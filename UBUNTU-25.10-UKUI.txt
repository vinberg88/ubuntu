Fix IP problem for X410. Cant find screen problem - UBUNTU 25.10 Questing Quokka and UKUI

FIRST OPEN POWERSHELL AND TYPE: ipconfig 

Last lines are IP-number for WSL.

SAVE IP HERE: 172.30.16.1

GO BACK TO UBUNTU 25.10 Questing Quokka Terminal AND COPY AND PASTE THIS IN TERMINAL.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service
sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here from POWERSHELL and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed for UBUNTU 25.10 and UKUI.

DONT STRESS IF YOU PUT WRONG IP ALL WILL STOP WORKING UNDER WSL.
