Update Repos from Ubuntu 26.10 to Ubuntu Tenacious T-Rex 27.04


sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak

sudo sed -i 's/stonking/tenacious/g' /etc/apt/sources.list.d/ubuntu.sources

sudo apt update && sudo apt dist-upgrade -y

---------------------------------------

Update from Stoneking 26.10 to Tenacious 27.04 in version file.

sudo nano /etc/os-release

Remove all in nano file and copy and paste this.

PRETTY_NAME="Ubuntu Tenacious T-Rex (development branch)"
NAME="Ubuntu"
VERSION_ID="27.04"
VERSION="27.04 (Tenacious T-Rex)"
VERSION_CODENAME=tenacious
ID=ubuntu
ID_LIKE=debian
HOME_URL="https://ubuntu.com"
SUPPORT_URL="https://ubuntu.com"
BUG_REPORT_URL="https://launchpad.net"
PRIVACY_POLICY_URL="https://ubuntu.comlegal/terms-and-policies/privacy-policy"
UBUNTU_CODENAME=tenacious
LOGO=ubuntu-logo

Next run this in terminal

sudo sh -c 'echo "Ubuntu Tenacious T-Rex 27.04 \n \l" > /etc/issue'
sudo sh -c 'echo "Ubuntu Tenacious T-Rex 27.04" > /etc/issue.net'

Cheack so it works: lsb_release -a

You will see this if all works.

No LSB modules are available.
Distributor ID: Ubuntu
Description:    Ubuntu Tenacious T-Rex (development branch)
Release:        27.04
Codename:       tenacious

Fix IP problem for X410. Cant find screen problems Xserver - Ubuntu Tenacious T-Rex 27.04

OPEN POWERSHELL AND TYPE: ipconfig

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL.

SAVE IP HERE FROM POWERSHELL: 172.30.16.1

Go back TO Ubuntu Tenacious T-Rex 27.04 Terminal AND COPY AND PASTE THIS IN TERMINAL.

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here from POWERSHELL and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed for Ubuntu Tenacious T-Rex 27.04 and KDE 6 =]
