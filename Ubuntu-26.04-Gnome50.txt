Install this programs Ubuntu 26.04

Fix dbus-broker error for Ubuntu 26.04

sudo apt install dbus-broker* dbus* -y
sudo apt install dbus-daemon* -y

sudo systemctl disable dbus-broker
sudo systemctl enable dbus

sudo mkdir -p /run/dbus
sudo chown messagebus:messagebus /run/dbus
