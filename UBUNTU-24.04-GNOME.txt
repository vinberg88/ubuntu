Fix IP problem for X410. Cant find screen problem. Look for ip adress in windows terminal / PowerShell: ipconfig

SAVE IP FROM POWERSHELL HERE: 172.30.16.1

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL in POWERSHELL so x410 works.

NOW GO BACK TO UBUNTU 24.04 Terminal and paste this.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here from Powershell and add nameserver to nano.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed =] for Ubuntu 24.04 and GNOME desktop.

Install Visual studio Code - Microsoft - Ubuntu 24.04

sudo apt-get install wget gpg
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg
echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" |sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null
rm -f packages.microsoft.gpg

sudo apt install apt-transport-https apt -y
sudo apt update
sudo apt install code -y
